# Manual Functional Testing Checklist

Reference: [requirements.md](requirements.md). Reviewed: 2026-10-14. Status: **Not executed**; source review only.

Scope: All main non-game features. Excludes Snake Game, visual presentation, responsiveness, performance, and automated testing.

Requirements take precedence. **Needs clarification** marks an unspecified business rule; observed behavior is not an approved requirement. **Review flag** identifies a source-review risk to reproduce, not a confirmed runtime failure. Other checks cover functional correctness and data integrity of available controls.

## Setup

- Use a test environment and two test accounts, A and B, with different saved carts and contact details. Use a separate browser profile for a clean guest session.
- Choose products P and Q with known prices p and q, different categories, and some shared/different ingredients. Have enough products for at least five pages and a comparison table that scrolls in both directions. Have empty and single-page categories available where possible.
- Record the configured quantity limit as M. **Needs clarification:** the requirements do not define M, minimum quantity, shipping charges, account/guest persistence rules, or order completion. Confirm these before judging policy-dependent cases; use M >= 3 for multi-quantity cases.
- Run cases labeled “both” as guest and signed-in user. Cart/checkout cases use A unless stated otherwise. Reset only the relevant test data between independent cases.
- For failure cases, open browser DevTools > Network, enable Preserve log and Disable cache, block the specified request, then reload or perform the action. Wait for retries to finish. Unblock and repeat to verify recovery. Use Offline for general connection failures and throttling for races. Do not change source code.
- For data-dependent cases, obtain prepared test records/responses from the test-environment owner. Mark unavailable fixtures or configuration changes as blocked, not passed. In local-storage cases, edit only this test site's `compare` key under DevTools > Application > Local Storage, and remove it after testing.
